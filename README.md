# Mortuary Realista

A free graphics mod for **The Mortuary Assistant** (Unity HDRP, IL2CPP) that runs on **BepInEx 6**.
It improves lighting, reflections, shadows, materials and color, and adds a **GRAPHICS MOD** tab inside the game's own **Options** menu so you can tune everything in-game.

*Versión en español más abajo.*

## Features

- **GRAPHICS MOD tab in the game's Options menu** (main menu and pause menu), built with the game's own checkboxes, dropdowns and sliders. Each option shows a short description when you hover over it. Changes apply instantly and are saved.
- **Quick presets:** Original / Low 4 GB / Medium 6 GB / Balanced / Maximum. On the first launch the mod picks one automatically from your graphics card's VRAM and your RAM; the preset matching your current settings is highlighted.
- **Lighting:** screen-space reflections (off in the base game), high-quality ambient occlusion, micro shadows, realistic indoor bounce light, higher-resolution shadows, optional volumetric fog with light shafts.
- **Materials:** stronger surface relief on walls, floors, stone and wood; per-material shine (tiles, glass, metal, fabric); finer skin detail and subsurface scattering; denser grass.
- **Cinematic & color:** tone mapping (Neutral / ACES), exposure, contrast, saturation, vignette, optional film grain, chromatic aberration, lens distortion, motion blur and depth of field.
- **Characters:** extra relief on every animated character and their clothes (corpses, protagonist, relatives, demons): muscles, veins, wrinkles, fabric; wet-looking eyes that catch the light (demon eyes untouched).
- **Body inspection:** fixes the metallic/plastic look skin had under the autopsy table light (softer table light and matte skin), including the tutorial bodies that use the game's "morphing" skin shader, the protagonist's arms and the access cards.
- **Realistic cremation fire (needs the texture pack):** the crematorium fire is drawn with animated real flames instead of a white blob of glowing orbs, and casts a flickering orange light on the room.
- **High-quality cutscenes:** the game's cutscene depth of field runs at high quality (no bright outlines around leaves and hair).
- **Dirt instead of grass (optional):** replaces the 3D grass outside with photographic dirt and stones, with no visible repetition (texture pack).
- **Realistic 3D grass (optional):** real grass blades generated by the mod, in natural clumps with bare patches, replacing the game's layered "carpet" grass. Only on the dirt areas; full detail near the camera. No wind (the game can't compile new shaders).
- **More trees:** 35 extra birches (copies of the game's own) planted only on the dirt around the mortuary, never on the street or the parking lot.
- **Realistic hair:** hairstyles switch to the game's own hair shader: fine strands and real hair shine instead of flat ribbons.
- **Skin scattering:** adjustable subsurface scattering of the skin profile (sharper pores and folds by default).
- **Realistic blood:** drained blood on the table looks dark red and wet instead of pale pink.
- **Corner shading:** ambient occlusion also darkens corners and joints under lamps, so furniture and objects sit on walls and floors instead of floating.
- **Readable clipboard:** the clipboard text no longer fades in curved areas or disappears when you move the camera, and the paper glows slightly so you can read it in the dark.
- **Level of detail and draw distance** multipliers, 16x anisotropic filtering.
- Menu language follows the game: Spanish if the game is in Spanish, English otherwise.

The mod **does not modify any game files** on disk; everything happens at runtime.

### Optional AI texture pack

The plugin can load higher-resolution versions of the game's textures (upscaled with AI). With a limited VRAM budget the plugin loads the most visible textures first (skin, walls, floors) and loads less important ones from a smaller mip level instead of skipping them. The pack's relief maps for walls, floors and wood also carry fine micro detail baked in (the game lacks the shader variant for a separate detail layer). That pack is **not included** in this repository because it is derived from the game's original textures, which belong to DarkStone Digital. It is offered as a separate optional download on Nexus Mods and GameBanana: **AI Texture Pack - Ultra 4K (~6 GB)**. The plugin loads only as many textures as fit in your graphics card's memory, most visible first. To install it, copy its `BepInEx` folder into the game folder like the plugin. The `herramientas/` folder contains the pipeline used to build it.

## Requirements

- The Mortuary Assistant (Steam, PC).
- **BepInEx 6 for Unity IL2CPP x64** (bleeding-edge build, tested with `6.0.0-be.793`): <https://builds.bepinex.dev/projects/bepinex_be>

## Installation

1. Install BepInEx 6 IL2CPP into the game folder and start the game once so BepInEx generates its files, then close it.
2. Copy the `BepInEx` folder from the release zip into the game folder (the plugin goes to `BepInEx/plugins/MortuaryRealista/`).
3. Start the game and open **Options → GRAPHICS MOD**.

**Linux / Steam Deck (Proton):** add this to the game's Steam launch options: `WINEDLLOVERRIDES="winhttp=n,b" %command%`

### Windows players: please report problems

The mod was developed and tested on Linux (Proton), using the same Windows build of BepInEx and the same plugin DLL that Windows players get. It could not be tested on native Windows yet (the author's Windows virtual machine cannot run this HDRP game, even without mods). If something goes wrong on Windows, please leave a comment on Nexus Mods, GameBanana or GitHub (Issues) with:

- what happens (black screen, crash, missing GRAPHICS MOD tab, wrong textures…),
- your graphics card (and its VRAM) and how much RAM you have,
- the file `BepInEx\LogOutput.log` from the game folder (and `Player.log` from `%USERPROFILE%\AppData\LocalLow\DarkStone Digital\The Mortuary Assistant` if the game doesn't start).

Every report helps fix it for everyone. Thank you!

### Keys

- **F8:** color effects on/off.
- **F9:** reload the configuration file.
- **F10:** save a screenshot in the game folder (`Capturas/`).

Configuration file: `BepInEx/config/angel.mortuary.terrorcine.cfg`.

### Uninstall

Delete `BepInEx/plugins/MortuaryRealista/`.

## Building

```
dotnet build -c Release
```
The project references the game's BepInEx interop assemblies (see `MortuaryRealista.csproj`, `GameDir`).

# Mortuary Realista (español)

Mod gráfico gratuito para **The Mortuary Assistant** (Unity HDRP, IL2CPP) que corre sobre **BepInEx 6**.
Mejora la iluminación, los reflejos, las sombras, los materiales y el color, y agrega la pestaña **MOD GRÁFICO** dentro del menú **Opciones** del propio juego para ajustarlo todo sin salir de él.

## Qué trae

- **Pestaña MOD GRÁFICO en Opciones** (menú principal y pausa), hecha con las mismas casillas, listas y barras del juego. Cada opción muestra una descripción al pasar el puntero. Los cambios se aplican al instante y se guardan.
- **Ajustes rápidos:** Original / Bajo 4 GB / Medio 6 GB / Equilibrado / Máximo. La primera vez el mod elige uno solo según la VRAM de tu tarjeta y tu RAM; el que coincide con tu configuración queda marcado.
- **Iluminación:** reflejos en pantalla (el juego los traía apagados), oclusión ambiental de calidad alta, microsombras, luz interior realista, sombras de mayor resolución y niebla volumétrica opcional con haces de luz.
- **Materiales:** más relieve en paredes, suelos, piedra y madera; brillo por material (azulejos, vidrio, metal, tela); más detalle y dispersión en la piel; pasto más tupido.
- **Cine y color:** mapeo tonal (Neutral / ACES), exposición, contraste, saturación, viñeteo y, opcionales, grano, aberración cromática, distorsión de lente, desenfoque de movimiento y profundidad de campo.
- **Personajes:** más relieve en todos los personajes animados y su ropa (cadáveres, protagonista, familiares, demonios): músculos, venas, arrugas, tela; ojos con brillo húmedo que reflejan la luz (los de demonios no se tocan).
- **Inspección del cuerpo:** arregla el aspecto metálico o plástico de la piel bajo el foco de la mesa de autopsias (foco más suave y piel mate).
- **Inspección del cuerpo y tutorial:** piel mate también en los cuerpos del tutorial (shader "BodyMorph" del juego), en los brazos de la protagonista y en las tarjetas de acceso.
- **Fuego realista del crematorio (requiere el pack de texturas):** llamas animadas reales en vez de un disco blanco de bolas brillantes.
- **Luz del fuego:** el crematorio ilumina la sala con luz naranja que parpadea.
- **Cinemáticas en alta calidad:** el desenfoque de fondo de las cinemáticas sin contornos claros en hojas y pelo.
- **Tierra en vez de pasto (opcional):** cambia el pasto 3D de afuera por tierra y piedras fotográficas, sin repetición visible (pack de texturas).
- **Pasto realista 3D (opcional):** hojas de pasto reales generadas por el mod, en matas desordenadas con zonas peladas, en vez del pasto "alfombra" de capas del juego. Solo sobre la tierra; detalle completo cerca de la cámara. Sin viento (el juego no permite compilar shaders nuevos).
- **Más árboles:** 35 abedules extra (copias de los del juego) plantados solo en la tierra alrededor de la funeraria, nunca en la calle ni en el estacionamiento.
- **Pelo realista:** los peinados pasan al shader de pelo del propio juego: hebras finas y brillo de pelo real en vez de tiras planas.
- **Dispersión de la piel:** ajuste de cuánto viaja la luz bajo la piel (por defecto marca más poros y pliegues).
- **Sangre realista:** la sangre del drenaje en la mesa se ve roja oscura y mojada en vez de rosada.
- **Sombra en rincones:** la oclusión ambiental también oscurece rincones y uniones bajo las lámparas, así los muebles y objetos se asientan en paredes y suelos en vez de flotar.
- **Portapapeles legible:** el texto ya no se deslava en las zonas curvas ni desaparece al mover la cámara, y el papel brilla un poco para leerlo a oscuras.
- **Nivel de detalle y distancia de dibujado** ajustables, filtrado anisotrópico 16x.
- El menú sale en el idioma del juego: español si el juego está en español; inglés en los demás.

El mod **no modifica ningún archivo del juego** en el disco: todo ocurre mientras el juego corre.

### Pack opcional de texturas IA

El plugin puede cargar versiones de mayor resolución de las texturas del juego (escaladas con IA). Con poca VRAM el plugin carga primero lo que más se ve (piel, paredes, suelos) y lo menos importante lo carga desde un nivel de mip menor en vez de dejarlo fuera. Los relieves del pack para paredes, suelos y madera llevan además microdetalle incluido (el juego no trae la variante de shader para una capa de detalle aparte). Ese pack **no está incluido** en este repositorio porque deriva de las texturas originales del juego, que son de DarkStone Digital. Se ofrece como descarga opcional aparte en Nexus Mods y GameBanana: **AI Texture Pack - Ultra 4K (~6 GB)**. El plugin carga solo las texturas que caben en la memoria de tu tarjeta de video, primero las que más se ven. Se instala igual que el plugin, copiando su carpeta `BepInEx` en la carpeta del juego. La carpeta `herramientas/` contiene el proceso con el que se genera.

## Requisitos

- The Mortuary Assistant (Steam, PC).
- **BepInEx 6 para Unity IL2CPP x64** (versión bleeding edge, probado con `6.0.0-be.793`): <https://builds.bepinex.dev/projects/bepinex_be>

## Instalación

1. Instala BepInEx 6 IL2CPP en la carpeta del juego, ábrelo una vez para que BepInEx genere sus archivos y ciérralo.
2. Copia la carpeta `BepInEx` del zip en la carpeta del juego (el plugin queda en `BepInEx/plugins/MortuaryRealista/`).
3. Abre el juego y entra a **Opciones → MOD GRÁFICO**.

**Linux / Steam Deck (Proton):** agrega en las opciones de lanzamiento de Steam: `WINEDLLOVERRIDES="winhttp=n,b" %command%`

### Jugadores de Windows: avisen si algo falla

El mod se hizo y se probó en Linux (Proton), con la misma versión de BepInEx para Windows y la misma DLL que recibe quien juega en Windows. Todavía no se pudo probar en un Windows real (la máquina virtual de Windows del autor no puede correr este juego HDRP, ni siquiera sin mods). Si en Windows algo no funciona, deja un comentario en Nexus Mods, GameBanana o GitHub (Issues) con:

- qué pasa (pantalla negra, se cierra, no aparece la pestaña MOD GRÁFICO, texturas raras…),
- tu tarjeta de video (y su VRAM) y cuánta RAM tienes,
- el archivo `BepInEx\LogOutput.log` de la carpeta del juego (y `Player.log` de `%USERPROFILE%\AppData\LocalLow\DarkStone Digital\The Mortuary Assistant` si el juego no arranca).

Cada aviso ayuda a arreglarlo para todos. ¡Gracias!

### Teclas

- **F8:** efectos de color sí/no.
- **F9:** recarga la configuración.
- **F10:** captura de pantalla en la carpeta del juego (`Capturas/`).

Configuración: `BepInEx/config/angel.mortuary.terrorcine.cfg`.

### Desinstalar

Borra `BepInEx/plugins/MortuaryRealista/`.
